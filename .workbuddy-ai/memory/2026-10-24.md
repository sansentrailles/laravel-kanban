### Найденные проблемы (приоритет — сверху)
1. Авторизация дырявая: `ColumnOrderRequest::authorize()` = true и `ColumnController@orders` не скоупит колонки доской; `CardOrderRequest` проверяет только перемещаемую карточку, не целевую колонку; комментарии (store/update/destroy) и чек-листы вообще без проверок, `{comment}` не привязан к `{card}`.
2. `AppLayout.vue` использует неопределённые `handleBoardSelect`, `showCreateBoardModal`, `showInviteModal`, `showShareModal`, `handleWorkspaceCreated` → кнопка «Новая доска», invite/share мертвы.
3. `Column.vue` вызывает несуществующий `archiveColumn` → TypeError по клику «Архивировать».
4. `CardPriority::High = 'hight'` (опечатка), приоритет не редактируется в UI (PrioritySelector не подключён), в `CardUpdateRequest` нет правила `priority`.
5. Мёртвый/битый код в моделях: `Card::scopOverdue` (опечатка), `is_completed_at`/`is_completed` не существуют, `scopeOrdered` использует несуществующий `Builder::order()`, `Board::withCardData` ссылается на `assignee`.
6. Отладочные хвосты в UI: `{{ column.title }} - {{ column.id }}`, `{{ card.title }} {{ card.id }}`.
7. `BoardController@show` не проверяет, что board принадлежит workspace из URL; грузит `comments.user` для всех карточек.
